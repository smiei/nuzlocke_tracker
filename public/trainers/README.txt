Place trainer PNG images here so they show up next to the names on the
Milestones page. If a file is missing, an initial-letter placeholder is shown
automatically - not an error.

These images are not part of the repo or the Docker image (copyrighted game
artwork) - provide them yourself. In Docker, mount this directory as a volume
(/app/public/trainers) and drop the files in there.

Expected file names (derived from the German names in levelcaps.json - the
file name always uses the German slug, regardless of UI language):

rocko.png       (Rocko / Brock)
misty.png       (Misty)
major-bob.png   (Major Bob / Lt. Surge)
erika.png       (Erika)
koga.png        (Koga)
sabrina.png     (Sabrina)
pyro.png        (Pyro / Blaine)
giovanni.png    (Giovanni)
lorelei.png     (Lorelei)
bruno.png       (Bruno)
agathe.png      (Agathe / Agatha)
siegfried.png   (Siegfried / Lance)
champ.png       (Champ / Champion - also used for the rival)

Recommended size: at least 80x80px, square (displayed cropped to a circle).
